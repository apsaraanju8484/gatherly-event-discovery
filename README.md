# Gatherly

Gatherly is a responsive event discovery and booking experience for finding local classes, food, music, and outdoor plans.

## Features

- Search events by name, category, venue, or city
- Filter by category and location; sort by date, price, or popularity
- Save favorite events in browser storage
- Reserve one or more event spots with a booking confirmation
- Join a local events newsletter (demo storage only)
- Responsive mobile navigation and reduced-motion support

## Run locally

Open `index.html` in a browser, or serve this folder with a static development server. No build step or backend is required.

Bookings and newsletter signups are demo-only and saved in the current browser's local storage. No payment is collected and no data is sent to a server.

## Built with

HTML, CSS, and vanilla JavaScript.
